📝 一步步教你做

1

第1步：安装Ubuntu Server 26.04并完成基础配置

用虚拟机或云服务器安装Ubuntu Server 26.04，安装时勾选OpenSSH Server以便远程连接。安装完成后用SSH登录，执行sudo apt update && sudo apt upgrade -y更新系统。接着设置主机名、时区，并创建一个有sudo权限的普通用户（如果安装时没建）。最后确认网络连通，能ping通外网。
💡 小贴士：安装时建议最小化安装，不要选额外的服务包，保持系统干净，后续按需安装。
2

第2步：向AI提问获取Docker安装命令

打开AI对话工具，输入提示词：“我是Ubuntu Server 26.04新手，请给出安装Docker Engine和Docker Compose的完整命令步骤，要求用官方apt仓库，并解释每条命令的作用。”AI会返回一套命令，包括安装依赖、添加GPG密钥、添加仓库、安装docker-ce等。你逐条复制执行，遇到不懂的就追问AI。
💡 小贴士：让AI解释每条命令，不要盲目复制粘贴，这是学习的关键。
3

第3步：执行安装并配置Docker

按照AI给出的命令依次执行：先安装ca-certificates、curl等依赖，然后添加Docker官方GPG密钥和apt仓库，接着sudo apt install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin -y。安装完成后启动Docker服务并设为开机自启：sudo systemctl enable --now docker。最后把当前用户加入docker组，避免每次用sudo：sudo usermod -aG docker $USER，然后重新登录生效。
💡 小贴士：加入docker组后必须退出SSH重新登录，否则组权限不生效。
4

第4步：验证安装并跑通第一个容器

执行docker version和docker compose version确认版本信息。然后运行sudo docker run hello-world，看到“Hello from Docker!”说明安装成功。再尝试运行一个Nginx容器：docker run -d -p 8080:80 --name mynginx nginx，然后在浏览器访问服务器IP:8080，看到Nginx欢迎页即证明容器网络正常。
💡 小贴士：如果访问不了，检查服务器防火墙或云安全组是否放行了8080端口。
5

第5步：用AI辅助排错与优化

如果某步报错，把错误信息完整复制给AI，并说明你的操作环境，AI会给出排查思路。常见问题包括GPG密钥下载失败、仓库地址错误、权限不足等。根据AI建议修复后，再让AI给出Docker常用配置优化建议，比如配置国内镜像加速器、设置日志轮转等。最后把整个流程整理成自己的笔记。
💡 小贴士：让AI用“一步一步教我”的方式回答，避免它一次性给太多信息。

❓ 常见问题

Ubuntu 26.04太新，Docker官方仓库支持吗？ ▼
如果官方仓库尚未收录26.04代号，可以暂时使用相邻LTS版本的仓库（如24.04），或改用Ubuntu自带docker.io包，但版本较旧。建议先问AI确认最新支持情况。
执行docker命令提示权限被拒绝怎么办？ ▼
说明当前用户不在docker组。执行sudo usermod -aG docker $USER后退出SSH重新登录即可。
拉取镜像很慢或失败怎么办？ ▼
配置国内镜像加速器，在/etc/docker/daemon.json中加入registry-mirrors，然后sudo systemctl restart docker。具体地址可让AI推荐当前可用的。
AI给的命令我不敢直接执行，怎么确保安全？ ▼
让AI逐条解释命令作用，对涉及删除、修改系统文件的命令格外警惕，可以先在测试虚拟机里跑一遍。
Docker Compose和docker-compose命令有什么区别？ ▼
新版是Docker Compose插件，命令为docker compose（中间空格）；旧版是独立二进制docker-compose。安装docker-compose-plugin后使用前者。
