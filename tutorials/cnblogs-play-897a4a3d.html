📝 一步步教你做

1

第1步：初始化项目并安装依赖

创建一个新的 Node.js 项目，运行 npm init -y 生成 package.json。然后安装 Stagehand 和 Playwright：npm install @browserbasehq/stagehand playwright。安装完成后运行 npx playwright install chromium 下载浏览器内核。
💡 小贴士：建议使用 pnpm 或 yarn 加速安装；如果网络慢，可设置 npm 镜像源。
2

第2步：配置环境变量与 LLM 连接

在项目根目录创建 .env 文件，写入 OPENAI_API_KEY=你的密钥。Stagehand 默认使用 OpenAI 的模型，也可以配置其他兼容 OpenAI 接口的 LLM 服务（如 DeepSeek、Ollama）。在代码中通过 dotenv 加载环境变量，或直接在初始化 Stagehand 时传入 apiKey。
💡 小贴士：如果使用本地模型，确保其支持 function calling 或 JSON 输出，否则 Stagehand 可能无法正确解析指令。
3

第3步：编写第一个 Stagehand 脚本

新建 index.js，引入 Stagehand 并初始化：const stagehand = new Stagehand({ env: 'LOCAL' }); await stagehand.init(); 然后获取 page 对象：const page = stagehand.page; 用 page.goto('https://example.com') 打开目标网页。接着用自然语言指令操作页面，例如 await page.act('点击登录按钮'); 或 await page.extract('提取页面所有文章标题');。
💡 小贴士：act 方法用于执行操作，extract 用于提取数据，observe 用于观察页面元素，三者配合使用更灵活。
4

第4步：运行脚本并观察 AI 操作过程

在终端运行 node index.js。Stagehand 会启动浏览器，AI 根据你的自然语言指令分析页面并执行对应操作。你可以在控制台看到 AI 的推理日志和操作结果。如果操作失败，日志会提示 AI 的理解偏差，方便调整指令。
💡 小贴士：首次运行时建议开启 headless: false 观察浏览器行为，调试稳定后再改为无头模式。
5

第5步：封装可复用的自动化任务

将常用操作封装成函数，例如 async function login(page, username, password) { await page.act(`在用户名输入框填写 ${username}`); await page.act(`在密码输入框填写 ${password}`); await page.act('点击登录按钮'); }。然后组合多个函数完成复杂流程，如登录后抓取数据并保存为 JSON 文件。
💡 小贴士：对于关键操作，可以结合 page.observe 先确认元素存在再执行，提高稳定性。

脚本成功启动浏览器，AI 自动完成登录、填表或数据提取等操作，控制台输出操作日志和提取结果，数据可保存为 JSON 或 CSV 文件。

❓ 常见问题

Stagehand 和直接写 Playwright 脚本有什么区别？ ▼
Playwright 需要精确的选择器和步骤，页面一变就失效；Stagehand 用自然语言指令，AI 能理解页面语义并自适应变化，维护成本更低，但执行速度略慢。
必须用 OpenAI 的 API 吗？ ▼
不是，Stagehand 支持任何兼容 OpenAI 接口的 LLM 服务，包括 DeepSeek、Ollama 本地模型等，只需在初始化时配置 baseURL 和 apiKey。
运行时报错「找不到元素」怎么办？ ▼
可能是 AI 对指令理解有偏差，尝试更具体的描述（如「点击蓝色登录按钮」而不是「点击按钮」），或先用 page.observe 查看页面元素结构。
Stagehand 能处理需要登录的网站吗？ ▼
可以，通过 act 指令填写账号密码并点击登录即可。对于复杂验证码，建议结合人工处理或使用 Browserbase 的云端浏览器服务。
这个框架适合生产环境吗？ ▼
Stagehand 目前仍在快速迭代，适合原型验证和内部工具。生产环境建议结合 Browserbase 的云浏览器服务，获得更好的稳定性和并发能力。
