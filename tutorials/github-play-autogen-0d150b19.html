AutoGen：让多个AI智能体组队干活

GitHub AutoGen · S级 官方一手 查看原文 →
📌 这是什么

AutoGen 是微软开源的多智能体协作框架，让你像组建团队一样，给多个 AI 分配角色，让它们自动对话、分工、调用工具，最终完成复杂任务。

🎯 为什么值得玩

过去我们使用单个 AI 时，往往需要反复调整提示词，遇到多步骤任务容易中断或遗漏。AutoGen 把「多个 AI 组队干活」这件事标准化了：你可以定义产品经理、程序员、测试员等角色，让它们互相评审、迭代，甚至自动执行代码。它适合自动化编程、数据分析、内容创作、流程审批等场景，GitHub 上已获得超过 6 万星标，是目前最流行的多智能体框架之一。

📝 一步步教你做

1

第1步：安装 AutoGen 并配置 API Key

打开终端，运行 pip install autogen-agentchat autogen-ext[openai] 安装最新版。然后在项目根目录创建 .env 文件，写入 OPENAI_API_KEY=你的密钥。如果使用其他模型，可参考官方文档配置 base_url 和 model 名称。
💡 小贴士：建议用虚拟环境（venv 或 conda）隔离依赖，避免版本冲突。
2

第2步：定义两个智能体角色

新建 Python 文件，导入 AssistantAgent 和 UserProxyAgent。创建一个「产品经理」智能体，系统提示词设为「你负责拆解需求并给出实现方案」；再创建一个「程序员」智能体，提示词设为「你根据方案编写 Python 代码并解释」。UserProxyAgent 用来代表人类发起对话，并可选开启代码执行。
💡 小贴士：角色提示词越具体，协作效果越好，比如指定输出格式、语言风格。
3

第3步：启动多智能体对话

调用 user_proxy.initiate_chat(manager, message="帮我写一个批量重命名文件的脚本")。AutoGen 会自动在智能体之间传递消息，产品经理给出方案，程序员写代码，必要时 user_proxy 会执行代码并反馈结果。你可以在终端看到完整对话过程。
💡 小贴士：设置 max_turns=10 可以防止对话无限循环，节省 token。
4

第4步：让智能体调用工具（可选）

通过 register_for_llm 和 register_for_execution 给智能体注册自定义函数，比如查询天气、读取数据库。这样智能体在对话中会自动判断是否需要调用工具，并传入参数。AutoGen 支持函数调用、代码执行、LangChain 工具等多种形式。
💡 小贴士：工具函数的 docstring 要写清楚参数和返回值，LLM 才能正确调用。
5

第5步：保存对话记录并调优

运行结束后，用 user_proxy.chat_messages 导出完整对话 JSON，分析哪些环节可以优化。常见调优手段包括：修改系统提示词、增加 critic 智能体做评审、调整 temperature、更换更强的模型。反复迭代几次，就能得到稳定的协作流程。
💡 小贴士：把成功的对话保存为模板，下次直接复用角色配置。

✨ 完成后你会得到

终端中会看到多个智能体轮流发言，产品经理给出方案，程序员输出代码，UserProxy 执行并返回结果。最终你会得到一个可运行的 Python 脚本，以及完整的协作对话记录。如果开启了代码执行，脚本会自动运行并输出重命名结果。

❓ 常见问题

AutoGen 和 LangChain 有什么区别？ ▼
LangChain 更偏向单智能体 + 工具链，AutoGen 专注多智能体对话协作，适合需要角色分工、互相评审的场景。两者可以结合使用。
没有 OpenAI API Key 能用吗？ ▼
可以。AutoGen 支持 Azure OpenAI、DeepSeek、Ollama、vLLM 等兼容 OpenAI 接口的模型，只需配置 base_url 和 api_key。
智能体对话停不下来怎么办？ ▼
设置 max_turns 参数限制轮数，或者给 UserProxyAgent 设置 human_input_mode="ALWAYS"，每轮人工确认。
代码执行安全吗？ ▼
默认在本地执行，建议使用 Docker 容器隔离，或设置 code_execution_config={"use_docker": True}，避免恶意代码。
需要多少 token 成本？ ▼
取决于模型和对话轮数。一般 3-5 个智能体、10 轮对话约消耗几万 token，用 GPT-4o mini 成本很低，建议先用小模型测试流程。

🚀 进阶玩法

  • 🔹 变体1：加入 Critic 智能体——在程序员和产品经理之外，增加一个「代码评审员」，专门挑错并给出修改建议，形成写-评-改闭环。
  • 🔹 变体2：GroupChat 群聊模式——使用 GroupChatManager 让 3 个以上智能体自由讨论，适合头脑风暴、方案选型等开放式任务。
  • 🔹 变体3：结合 RAG 做知识库问答——给智能体注册检索工具，从本地文档或向量数据库中查找资料，再让多个智能体协作生成答案。
