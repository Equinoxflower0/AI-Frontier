🎯 为什么值得玩

在 AIGC 问答类产品中，用户打开页面时通常需要自动创建一个对话会话，并展示一组热门问题引导用户提问。本玩法基于 SpringBoot 分层架构，实现 UUID 会话 ID 生成与入库持久化，同时将热门问题配置放在 Nacos 中，前端点击“换一换”即可随机刷新示例问题。这套方案适合需要快速搭建 AI 助手初始化能力的开发者，代码结构清晰，可直接复用到实际项目中。

📝 一步步教你做

1

第1步：初始化 SpringBoot 项目与数据库表

使用 Spring Initializr 创建项目，勾选 Spring Web、MyBatis-Plus、MySQL Driver 和 Nacos Config 依赖。在 MySQL 中创建数据库 ai_chat，并新建会话表 chat_session，字段包括 id（bigint 自增）、session_id（varchar 36，唯一索引）、user_id（bigint）、create_time（datetime）。在 application.yml 中配置数据源和 Nacos 注册中心地址。
💡 小贴士：session_id 建议加唯一索引，避免 UUID 重复导致插入失败；Nacos 命名空间建议按环境隔离。
2

第2步：编写会话创建接口

创建 ChatSessionController，提供 POST /api/chat/session 接口。在 Service 层使用 UUID.randomUUID().toString() 生成会话 ID，结合当前登录用户 ID 组装实体，通过 MyBatis-Plus 的 save 方法入库。接口返回 sessionId 和创建时间，前端拿到后存入本地缓存，后续对话请求携带该 sessionId。
💡 小贴士：如果用户未登录，可先用设备指纹或临时游客 ID 代替 user_id，后续再绑定。
3

第3步：在 Nacos 中配置热门问题

登录 Nacos 控制台，在配置管理中新建 Data ID 为 ai-chat-hot-questions.yaml 的配置，内容为 YAML 数组，每项包含 question 和 category 字段。在 SpringBoot 项目中通过 @NacosValue 或 @ConfigurationProperties 注入该配置，并编写 HotQuestionService 提供获取全部问题的方法。
💡 小贴士：配置内容建议用 YAML 格式，便于阅读和维护；修改后 Nacos 会自动推送，无需重启应用。
4

第4步：实现“换一换”随机接口

在 HotQuestionController 中提供 GET /api/chat/hot-questions/random 接口，从 HotQuestionService 获取全部问题列表，使用 Collections.shuffle 或 Random 随机抽取 N 条（例如 4 条）返回。前端点击“换一换”按钮时调用该接口，替换展示的问题列表。
💡 小贴士：如果问题数量较少，可先打乱再取前 N 条，避免重复抽取同一条；可加缓存减少 Nacos 读取频率。
5

第5步：前端联调与验证

启动 SpringBoot 应用和 Nacos，使用 Postman 调用会话创建接口，确认返回 sessionId 且数据库中有记录。再调用热门问题随机接口，多次请求观察返回问题是否变化。前端页面加载时自动调用会话创建接口，并展示随机热门问题；点击“换一换”按钮触发随机接口刷新列表。
💡 小贴士：联调时可在 Nacos 中临时增加几条测试问题，方便观察随机效果；注意跨域配置。

✨ 完成后你会得到

打开前端页面后，系统自动创建一个会话并在数据库中生成一条 session_id 记录；页面展示 4 条热门问题，点击“换一换”按钮后问题列表随机刷新为另一组问题。Postman 调用接口均返回 200 且数据正确。

❓ 常见问题

UUID 生成的 session_id 会不会重复？ ▼
UUID 重复概率极低，但建议数据库加唯一索引兜底，插入失败时重试一次即可。
Nacos 配置修改后需要重启应用吗？ ▼
不需要，使用 @NacosValue 注解并开启自动刷新，配置变更会实时推送到应用。
热门问题数量很少时“换一换”效果不明显怎么办？ ▼
可以增加问题池数量，或采用轮询加随机混合策略，保证每次至少有一条变化。
会话表需要设置过期时间吗？ ▼
建议增加 expire_time 字段或定时任务清理长期未活跃的会话，避免数据无限增长。
没有 Nacos 环境可以先用本地配置吗？ ▼
可以，先用 application.yml 中的本地配置模拟，后续再迁移到 Nacos，接口层无需改动。

🚀 进阶玩法

  • 🔹 变体2：会话创建时同步调用大模型接口生成欢迎语，返回 sessionId 的同时附带个性化开场白，提升用户体验。
