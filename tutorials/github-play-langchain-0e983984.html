📝 一步步教你做

1

第1步：安装 MarkItDown

打开终端，运行 pip install markitdown[all] 安装全部依赖（包括 PDF、Office 等格式支持）。如果只想支持部分格式，可以只安装 markitdown[pdf,docx] 等。安装完成后输入 markitdown --help 验证是否成功。
💡 小贴士：建议在虚拟环境中安装，避免污染全局 Python 包。
2

第2步：单文件转换（命令行）

在终端执行 markitdown 你的文件.pdf > output.md，即可将 PDF 转为 Markdown 并保存到 output.md。支持直接输出到终端查看，例如 markitdown report.docx。对于 Excel 文件，会保留表格结构为 Markdown 表格。
💡 小贴士：如果文件名包含空格，请用引号包裹，如 markitdown "my file.pdf"。
3

第3步：批量转换多个文件

使用 shell 循环批量处理：for file in *.pdf; do markitdown "$file" > "${file%.pdf}.md"; done。也可以写一个简单的 Python 脚本，调用 markitdown 库遍历文件夹，适合成百上千个文档的场景。
💡 小贴士：批量转换前先备份原文件，避免意外覆盖。
4

第4步：用 Python API 集成到工作流

在 Python 中导入 from markitdown import MarkItDown，创建 md = MarkItDown()，然后 result = md.convert("文件路径")，最后用 result.text_content 获取 Markdown 文本。可以轻松接入 LangChain、LlamaIndex 等框架，构建 RAG 知识库。
💡 小贴士：对于大文件，建议分块处理，避免内存占用过高。
5

第5步：处理特殊格式与优化输出

MarkItDown 支持 PDF、DOCX、XLSX、PPTX、图片（OCR）、音频（转录）等。如果转换结果不理想，可以尝试调整参数，例如对 PDF 启用 pdf 专用解析器。对于扫描版 PDF，需要额外安装 OCR 依赖（如 tesseract）。
💡 小贴士：图片和音频转换需要额外安装依赖，参考官方 README 的 optional dependencies 部分。

✨ 完成后你会得到

转换后得到结构清晰的 Markdown 文件，标题、列表、表格、链接等格式保留完整，可以直接粘贴到 Obsidian、Notion 或作为 LLM 的输入文本。批量转换后，整个文件夹的文档都变成 .md 文件。

❓ 常见问题

MarkItDown 支持哪些文件格式？ ▼
支持 PDF、Word (DOCX)、Excel (XLSX)、PowerPoint (PPTX)、图片、音频、HTML、CSV、JSON、XML 等，完整列表见 GitHub README。
转换后表格错乱怎么办？ ▼
MarkItDown 对简单表格支持较好，复杂合并单元格可能不完美。可以尝试用 pandas 读取 Excel 后手动转 Markdown，或使用专门的表格转换工具。
扫描版 PDF 无法提取文字？ ▼
扫描版 PDF 是图片，需要 OCR。安装 markitdown[pdf] 和 tesseract，或先用 OCR 工具转成文本再处理。
转换速度慢怎么优化？ ▼
大文件或批量转换时，可以多进程并行处理，或只安装需要的格式依赖以减少加载时间。
MarkItDown 和 Pandoc 有什么区别？ ▼
Pandoc 更通用但配置复杂，MarkItDown 专为 LLM 优化，输出更干净，且直接提供 Python API，适合集成到 AI 工作流。
