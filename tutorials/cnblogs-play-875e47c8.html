❓ 常见问题

没有 Plus 账号能用吗？ ▼
基础对话可以，但 MCP 接入和自定义 GPT 通常需要 Plus/Pro 或支持 MCP 的客户端，建议先确认账号权限。
lustereczko-mcp 启动报错怎么办？ ▼
检查 Node.js 版本是否 18+，依赖是否安装完整，端口是否被占用；查看终端日志定位具体错误。
生成的 UI 能导出吗？ ▼
可以，让 AI 把最终 UI 以 HTML/CSS/JS 代码块输出，复制保存为 .html 文件即可在浏览器独立运行。
为什么 AI 不调用 MCP 工具？ ▼
提示词中未明确要求使用 lustereczko，或 MCP 客户端未正确连接；在提示词里写明“请调用 lustereczko 生成 UI”并检查连接状态。
支持哪些图表类型？ ▼
取决于 AI 生成的库（如 Chart.js、ECharts），在提示词中指定图表库和类型即可，例如“用 ECharts 画折线图”。
