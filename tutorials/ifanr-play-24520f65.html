❓ 常见问题

GPT-6.2 工具链和普通函数调用有什么区别？ ▼
工具链支持多工具协同和自主决策，模型可连续调用多个工具完成复杂任务，而普通函数调用通常只执行单次指定函数。
为什么模型不调用我定义的工具？ ▼
常见原因：工具 description 太模糊、prompt 未明确要求使用工具、或 tool_choice 设置不当。建议在 prompt 中写“必须使用工具”并细化描述。
工具执行结果太长导致 token 超限怎么办？ ▼
在回传前对结果做截断或摘要，只保留关键字段。也可让模型先调用“摘要工具”压缩内容。
国内网络如何稳定调用 OpenAI API？ ▼
需配置代理或使用合规的 API 中转服务，注意遵守当地法律法规。建议在测试环境先用小流量验证。
工具链调用失败如何调试？ ▼
打印完整请求和响应 JSON，检查 tool_calls 的 id 和参数格式。用 Postman 单独重放请求，排除代码层问题。
