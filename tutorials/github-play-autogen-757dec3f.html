📝 一步步教你做

1

第1步：克隆仓库并搭好运行环境

打开终端执行 git clone https://github.com/microsoft/ai-agents-for-beginners.git，进入目录后创建虚拟环境 python -m venv venv 并激活。然后 pip install -r requirements.txt 安装依赖。最后用 jupyter notebook 或 VS Code 打开任意 .ipynb 文件，确认能正常启动。
💡 小贴士：建议单独建一个 conda 环境，避免和本机其他项目的包版本冲突。
2

第2步：配置模型访问密钥

在项目根目录创建 .env 文件，按教程说明填入 OPENAI_API_KEY 或 Azure OpenAI 的 endpoint、key、deployment 名称。多数 Notebook 会通过 python-dotenv 自动读取这个文件。配置好后先跑一个最简单的“Hello Agent”单元格，确认模型能正常返回内容。
💡 小贴士：不要把 .env 提交到 Git，仓库里通常有 .env.example 可以复制改名。
3

第3步：按顺序刷前几课，理解 Agent 基本结构

从第 1 课开始，依次学习“什么是 AI Agent”“探索 AI Agent 框架”“理解 Agentic 设计模式”等基础内容。每节课都先读 Markdown 讲解，再逐格运行代码，观察输入输出。重点理解 Agent 如何接收任务、调用模型、返回结果。
💡 小贴士：不要跳课，前几课的概念是后面工具调用和多智能体的基础。
4

第4步：动手做工具调用和记忆模块

进入工具调用相关课程，跟着 Notebook 把自定义函数注册成 Agent 可调用的工具，比如查天气、算汇率。再学习记忆模块，让 Agent 在多轮对话中记住上下文。运行后尝试修改函数参数，观察 Agent 行为变化。
💡 小贴士：工具函数的 docstring 要写清楚，模型靠它判断什么时候调用这个工具。
5

第5步：搭建多智能体协作小项目

学习多智能体协作课程，用 AutoGen 或 Semantic Kernel 创建多个角色，比如“产品经理”“程序员”“测试员”，让它们围绕一个任务互相讨论。运行示例后，尝试把任务换成你自己的小需求，比如“写一个待办清单网页”。
💡 小贴士：角色设定越具体，智能体之间的对话越有方向，别只写“你是助手”。
6

第6步：选一个方向做自己的 Agent 并复盘

从 18 课里挑一个你最感兴趣的方向，比如 RAG、代码执行、多模态或生产部署，基于示例改造成自己的小项目。完成后回到仓库 Star 并阅读 Issues，看看别人怎么扩展。把踩坑记录写成笔记，方便以后复用。
💡 小贴士：先跑通再优化，不要一上来就追求完美架构。

✨ 完成后你会得到

你能独立运行 18 课中的大部分 Notebook，理解 AI Agent 的基本组成（模型、工具、记忆、规划、多智能体），并拥有一个自己改造的小型 Agent 项目。

❓ 常见问题

没有 OpenAI API Key 能学吗？ ▼
可以。部分课程支持 Azure OpenAI、GitHub Models 或本地模型，但多数示例默认需要模型接口，建议至少准备一个可用的 API Key。
需要很强的 Python 基础吗？ ▼
不需要。会基本的变量、函数和 pip 安装即可，Notebook 已经把复杂逻辑拆成可运行的单元格。
18 课要全部学完吗？ ▼
不一定。前 6-8 课是核心，后面可按兴趣选学。想快速上手可以先看工具调用和多智能体协作。
运行代码报错怎么办？ ▼
先检查 Python 版本和依赖是否按 requirements.txt 安装，再确认 .env 配置正确。也可以去 GitHub Issues 搜报错关键词。
这个教程和 LangChain 官方教程有什么区别？ ▼
它更偏微软生态（AutoGen、Semantic Kernel、Azure），但概念通用，且结构更系统，适合从零建立完整认知。
