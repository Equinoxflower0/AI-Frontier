📝 一步步教你做

1

第1步：安装并配置 openEuler Agent 运行时

在 openEuler 24.03 上执行 `sudo dnf install openeuler-agent-runtime` 安装运行时。然后启用并启动服务：`sudo systemctl enable --now agent-runtime`。检查状态 `systemctl status agent-runtime` 确保 active。最后将当前用户加入 agent 组：`sudo usermod -aG agent $USER` 并重新登录。
💡 小贴士：如果 dnf 找不到包，先运行 `sudo dnf update` 并添加 openEuler 官方源。
2

第2步：创建并注册你的第一个 Agent

使用 Agent SDK 初始化项目：`agent-sdk init my-agent --template=basic`。进入目录后编辑 `agent.yaml`，填写名称、入口脚本和所需能力（如文件读写、网络访问）。运行 `agent-sdk register my-agent` 将 Agent 注册到系统总线。注册成功后可用 `agent-sdk list` 查看已注册 Agent。
💡 小贴士：能力声明要最小化，只申请实际需要的权限，便于系统做安全隔离。
3

第3步：编写 Agent 逻辑并调用系统工具

在 `main.py` 中导入 `openeuler_agent` 模块，使用 `@agent.task` 装饰器定义任务函数。通过 `agent.tools.call('file.read', path)` 调用系统工具，或使用 `agent.bus.publish('topic', data)` 与其他 Agent 通信。本地测试：`agent-sdk run my-agent --task=hello`。确认输出符合预期后，用 `agent-sdk deploy my-agent` 部署为常驻服务。
💡 小贴士：调试时开启 `--log-level=debug` 查看系统总线消息流，快速定位调用失败原因。
4

第4步：配置资源隔离与可观测性

编辑 `/etc/agent-runtime/config.yaml`，为 Agent 设置 CPU/内存限额和超时时间。启用内置的 Prometheus 指标导出：`metrics.enabled: true`。重启运行时后，访问 `http://localhost:9090/metrics` 查看 Agent 运行指标。结合 Grafana 导入官方看板模板，监控任务成功率与延迟。
💡 小贴士：生产环境建议为每个 Agent 单独设置 cgroup 限额，避免单个 Agent 耗尽系统资源。
5

第5步：集成外部 AI 模型并完成端到端验证

在 `agent.yaml` 的 `env` 中配置模型 API Key（如 OpenAI 或本地 Ollama 地址）。修改任务函数，调用模型生成计划，再通过 `agent.tools.call` 执行系统操作。运行 `agent-sdk test my-agent --scenario=full` 进行端到端测试。观察日志和指标，确认 Agent 能正确调用工具并返回结果。
💡 小贴士：先用 mock 模型测试工具链，再切换真实模型，避免调试时产生不必要的 API 费用。

✨ 完成后你会得到

完成以上步骤后，你将在 openEuler 上拥有一个已注册、可隔离运行、具备可观测性的 AI Agent。通过 `agent-sdk list` 能看到 Agent 状态为 running，Prometheus 指标正常上报，且 Agent 能按任务调用系统工具并返回结果。

❓ 常见问题

openEuler Agent 运行时和普通 Docker 运行 Agent 有什么区别？ ▼
运行时提供系统级 Agent 注册、能力权限管理和统一通信总线，而 Docker 只做进程隔离，缺少 Agent 生命周期和工具调用的标准抽象。
没有 openEuler 物理机，可以用虚拟机或 WSL 吗？ ▼
可以。推荐用 VirtualBox 或 VMware 安装 openEuler 24.03 镜像；WSL 暂不支持 agent-runtime 的全部内核特性。
Agent SDK 支持哪些编程语言？ ▼
目前官方主要支持 Python，社区有 Go 和 Rust 的早期绑定，建议优先使用 Python 以获得完整功能。
注册 Agent 时提示权限不足怎么办？ ▼
确认当前用户已在 agent 组中，并重新登录；或使用 `sudo agent-sdk register` 临时提权注册。
如何卸载或停止一个已部署的 Agent？ ▼
运行 `agent-sdk stop my-agent` 停止服务，`agent-sdk unregister my-agent` 从总线移除，再删除项目目录即可。
