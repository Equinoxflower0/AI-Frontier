📝 一步步教你做

1

第1步：确认 GPT‑6 模型权限并获取 API Key

登录 OpenAI 平台，进入 API Keys 页面创建一个新的密钥。然后在模型列表中确认 gpt-6 或 gpt-6-turbo 是否可用。新模型价格约为上一代的一半，建议先充值 5 美元测试。
💡 小贴士：API Key 只显示一次，务必立即复制保存到密码管理器中。
2

第2步：在 Zapier 中创建 ChatGPT 动作

登录 Zapier，新建一个 Zap，选择触发应用（例如 Google Sheets 的新行），然后添加动作应用 OpenAI。在动作中选择 Send Prompt，模型选 gpt-6，粘贴你的 API Key。在 Prompt 字段中写入你的任务指令，例如“请把以下内容改写成小红书风格：{{内容}}”。
💡 小贴士：Prompt 中可以用 {{字段名}} 动态插入表格数据，实现批量处理。
3

第3步：设计你的提示词模板

在 Prompt 中明确角色、任务和输出格式。例如：“你是一名资深科技编辑，请用 200 字总结以下文章，并列出 3 个关键点。输出格式：摘要 + 要点列表。文章内容：{{article}}”。GPT‑6 对结构化指令理解更好，建议用分隔符区分指令和内容。
💡 小贴士：把常用提示词保存到 Notion 或备忘录，方便复用和迭代。
4

第4步：连接输出端并测试

在 Zapier 中添加第二个动作，例如 Google Sheets 的“更新行”或 Gmail 的“发送邮件”，把 GPT‑6 的输出写入指定列或发送到邮箱。点击测试，检查返回内容是否符合预期。如果格式不对，回到 Prompt 调整指令。
💡 小贴士：先用 3-5 条样本数据测试，确认稳定后再批量运行。
5

第5步：批量运行与成本监控

在 Google Sheets 中填入待处理内容，Zapier 会自动逐行调用 GPT‑6。你可以在 OpenAI 后台的 Usage 页面查看 token 消耗和费用。由于 GPT‑6 价格腰斩，处理 1000 条 500 字内容成本通常不到 1 美元。
💡 小贴士：设置 Zapier 的每日运行上限，避免意外超支。
