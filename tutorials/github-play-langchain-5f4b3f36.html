📝 一步步教你做

1

第1步：安装 LangChain 和依赖

打开终端，创建虚拟环境（可选但推荐）：python -m venv venv，然后激活。接着安装核心包：pip install langchain langchain-openai。如果你要用其他模型，把 langchain-openai 换成对应包，比如 langchain-community。安装完成后用 pip list 确认版本。
💡 小贴士：国内用户可加 -i https://pypi.tuna.tsinghua.edu.cn/simple 加速下载。
2

第2步：配置 API Key 环境变量

在终端设置 OPENAI_API_KEY：Linux/Mac 用 export OPENAI_API_KEY='sk-xxx'，Windows 用 set OPENAI_API_KEY=sk-xxx。也可以写在 .env 文件里，然后用 python-dotenv 加载。建议不要硬编码在代码里，避免泄露。
💡 小贴士：如果用的是兼容接口，同时设置 OPENAI_BASE_URL 指向你的服务地址。
3

第3步：写一个最小可用的智能体脚本

新建 agent_demo.py，导入 ChatOpenAI 和 create_react_agent。定义一个简单工具，比如用 @tool 装饰器写一个查天气的函数。把模型、工具和提示词传给 create_react_agent，然后调用 invoke 传入问题。运行 python agent_demo.py，观察智能体是否自动选择工具并返回答案。
💡 小贴士：提示词里明确写“你可以使用以下工具”，并给工具起清晰的名字，模型更容易选对。
4

第4步：加入记忆让智能体记住上下文

在创建智能体时传入 memory 参数，比如 ConversationBufferMemory。这样多轮对话时，智能体能记住之前聊过的内容。测试方法：先问“我叫小明”，再问“我叫什么”，看它能否答对。如果答对，说明记忆生效。
💡 小贴士：记忆会消耗更多 token，长对话建议用 ConversationSummaryMemory 压缩历史。
5

第5步：运行并调试你的智能体

在脚本里加 print 输出中间步骤，或者设置 langchain.debug = True 查看详细日志。观察智能体是否按预期调用工具、参数是否正确。如果报错，先检查 API Key 和网络，再检查工具函数的参数类型是否匹配。
💡 小贴士：用 LangSmith 可以可视化追踪每一步，免费额度足够个人调试。

❓ 常见问题

没有 OpenAI API Key 能用吗？ ▼
可以，LangChain 支持 Azure OpenAI、Anthropic、通义千问、Ollama 本地模型等，换对应的 ChatModel 类即可。
安装时提示版本冲突怎么办？ ▼
先升级 pip：pip install --upgrade pip，然后单独安装 langchain-core 和 langchain-openai，避免一次装太多包。
智能体不调用工具，直接回答怎么办？ ▼
检查提示词是否明确告诉它可以用工具，工具描述是否清晰，以及模型是否支持 function calling。可以换更强的模型试试。
运行报错 RateLimitError 怎么处理？ ▼
说明 API 调用频率超限，降低请求频率或升级套餐。本地调试可以加 time.sleep 控制节奏。
这个智能体能部署成网页服务吗？ ▼
可以，用 FastAPI 或 Flask 包一层接口，再把 LangChain 智能体作为后端逻辑即可。
