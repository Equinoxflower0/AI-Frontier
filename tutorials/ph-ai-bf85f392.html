GBrain：给你的AI装上私人记忆和技能包

GBrain 能让你把私人记忆、常用工具和技能包像插件一样插进任何 AI，从此告别每次重复交代背景的麻烦。

🎯 为什么值得玩

很多人用 AI 时都有这样的痛点：每次开新对话都要重新说明自己的身份、项目背景、写作风格，甚至要重新粘贴一堆资料。GBrain 的思路是把这些「个人上下文」抽出来，做成可复用的记忆库和技能包，再通过 API 或插件方式注入到任意 AI 客户端。它适合内容创作者、开发者、产品经理等需要长期与 AI 协作的人，一次配置，处处调用。

🧰 你需要准备

  • GBrain 账号 → 访问
    用于创建和管理你的记忆库、工具与技能包
  • 任意支持自定义 API 的 AI 客户端 → 访问
    如 ChatGPT（自定义 GPT）、Claude、Cursor、Raycast AI 等，用于接入 GBrain
  • 你的个人资料文档
    提前整理好个人简介、项目背景、写作风格说明等文本，方便导入
  • API Key 管理工具 → 访问
    如 1Password 或环境变量文件，安全存放 GBrain 的 API Key

📝 一步步教你做

1

第1步：注册 GBrain 并创建第一个记忆库

打开 GBrain 官网，用邮箱或 Google 账号注册。进入控制台后点击「New Memory」创建一个记忆库，命名为「我的个人上下文」。在编辑区粘贴你的个人简介、常做项目、写作偏好等基础信息，保存后系统会生成一个 Memory ID。
💡 小贴士：记忆库内容建议控制在 500-1000 字，太短效果弱，太长可能超出部分 AI 的上下文窗口。
2

第2步：添加工具与技能包

在控制台切换到「Tools & Skills」标签，点击「Add Tool」。你可以添加常用的外部工具（如天气 API、搜索 API）或纯提示词技能（如「小红书爆款标题生成器」）。每个技能包填写名称、触发关键词和具体提示词模板，保存后与刚才的记忆库关联。
💡 小贴士：技能包的触发关键词要具体，比如「写标题」比「标题」更不容易误触发。
3

第3步：获取 API Key 并配置到 AI 客户端

在 GBrain 控制台的「Settings → API Keys」中生成一个 Key 并复制。然后打开你的 AI 客户端（以 ChatGPT 自定义 GPT 为例），在「Actions」或「知识库」设置里填入 GBrain 的 API 端点与 Key。如果是 Cursor 或 Raycast，则在插件配置中粘贴 Key。
💡 小贴士：API Key 不要直接写在公开的提示词里，建议用环境变量或客户端自带的密钥管理功能。
4

第4步：在对话中调用记忆与技能

配置完成后，在 AI 对话中直接说「调用我的 GBrain 记忆」或使用你设定的触发词（如「用我的风格写一段」）。AI 会自动从 GBrain 拉取你的个人上下文和对应技能包，然后按你的偏好生成内容。你可以随时在 GBrain 控制台更新记忆库，AI 下次调用时就会用最新版本。
💡 小贴士：第一次调用时建议先问 AI「你看到了哪些关于我的信息？」，确认记忆注入成功。
5

第5步：迭代与分享技能包

使用一两周后，回顾哪些技能包最常用、哪些记忆内容需要补充。在 GBrain 中直接编辑对应条目即可。你还可以把成熟的技能包导出为 JSON，分享给同事或社区，或者从社区导入别人做好的技能包快速起步。
💡 小贴士：定期清理过时的记忆内容，避免 AI 被旧信息干扰。

✨ 完成后你会得到

配置完成后，你在任何接入 GBrain 的 AI 客户端中提问时，AI 都能自动带上你的个人背景、写作风格和常用工具，不再需要每次重复交代。例如你说「帮我写周报」，AI 会直接按你公司的格式和你的语气输出，而不是先问你「请问你的职位是？」。

❓ 常见问题

GBrain 支持哪些 AI 客户端？ ▼
理论上任何支持自定义 API 或插件系统的客户端都可以，比如 ChatGPT 自定义 GPT、Claude、Cursor、Raycast、Obsidian 插件等。具体以 GBrain 官方文档为准。
我的私人数据安全吗？ ▼
GBrain 声称数据加密存储，但建议不要放入密码、身份证号等敏感信息。API Key 也要妥善保管，避免泄露。
记忆库和技能包有什么区别？ ▼
记忆库存放「关于你的静态信息」（身份、背景、偏好），技能包存放「可复用的动态能力」（提示词模板、工具调用逻辑）。两者可以独立使用，也可以组合。
免费版够用吗？ ▼
免费版通常有记忆条数或调用次数限制，个人轻度使用一般够用。如果重度依赖或团队协作，再考虑升级付费版。
更新记忆后需要重新配置 AI 客户端吗？ ▼
不需要。GBrain 是实时拉取的，你更新记忆库后，AI 下次调用时自动获取最新内容，客户端配置不用动。

🚀 进阶玩法

  • 🔹 变体1：团队共享记忆库——为团队创建一个「项目上下文」记忆库，包含产品文档、术语表、品牌语气，所有成员接入后 AI 回答风格统一。
  • 🔹 变体2：多角色技能包切换——创建「写作模式」「编程模式」「分析模式」三个技能包，在对话中用触发词切换，让同一个 AI 快速扮演不同角色。
  • 🔹 变体3：结合自动化工具——用 Zapier 或 Make 把 GBrain 与 Notion、Slack 连接，当 Notion 页面更新时自动同步到记忆库，实现记忆自动保鲜。

💡 一句话总结

GBrain 的本质是把「你」变成 AI 的可插拔模块，一次整理，处处调用，让 AI 真正记住你是谁、会什么。
