📝 一步步教你做

1

第1步：准备 Ubuntu 虚拟机并安装依赖

在 VMware 或 VirtualBox 中创建 Ubuntu 22.04 虚拟机，分配至少 4GB 内存和 20GB 磁盘。启动后更新系统：sudo apt update && sudo apt upgrade -y。安装 Python、pip、git 等基础工具：sudo apt install python3 python3-pip git -y。确保虚拟机网络通畅，能访问外网。
💡 小贴士：建议开启虚拟机共享文件夹或使用 SSH 连接，方便宿主机与虚拟机传输文件。
2

第2步：克隆 OSWorld 仓库并安装 Python 依赖

在虚拟机终端中执行：git clone https://github.com/xlang-ai/OSWorld.git，然后进入目录：cd OSWorld。创建虚拟环境：python3 -m venv venv，激活：source venv/bin/activate。安装依赖：pip install -r requirements.txt。如果遇到缺少系统库，根据报错安装对应的 apt 包。
💡 小贴士：安装依赖时建议使用国内镜像源加速，如 pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple。
3

第3步：配置 Claude API 并设置 Agent

在 OSWorld 中，Agent 需要调用大模型。设置环境变量：export ANTHROPIC_API_KEY='你的API Key'。根据官方文档，选择或编写一个使用 Claude 的 Agent 配置文件，通常位于 agent 目录下。确保配置中指定模型为 claude-3-5-sonnet 等可用版本。也可以参考 OpenInterpreter 的 Claude 集成方式。
💡 小贴士：API Key 不要硬编码在代码中，使用环境变量或 .env 文件管理，避免泄露。
4

第4步：启动虚拟机环境并运行示例任务

OSWorld 需要连接虚拟机执行操作。按照官方文档，启动虚拟机并确保 SSH 或 VNC 可访问。然后运行一个简单任务，例如：python run.py --task_id 0 --agent claude。任务 ID 对应 OSWorld 中的具体任务，可查看 tasks 目录。观察 Agent 是否自动打开应用并执行操作。
💡 小贴士：首次运行建议选择简单任务（如打开浏览器访问网页），便于排查环境问题。
5

第5步：查看结果与日志，调整 Agent 行为

任务运行后，终端会输出 Agent 的思考过程和操作步骤。检查任务是否成功完成，OSWorld 会给出评分。如果失败，查看日志中的错误信息，可能是 API 调用失败、操作超时或依赖缺失。根据日志调整 Agent 的提示词或重试策略。
💡 小贴士：可以增加 --debug 参数输出更详细日志，方便定位问题。

❓ 常见问题

没有 Claude API Key 可以运行吗？ ▼
可以替换为其他支持工具调用的模型，如 GPT-4o 或开源模型，但需要修改 Agent 配置中的模型调用部分。
虚拟机中操作延迟很高怎么办？ ▼
确保虚拟机分配足够资源，关闭不必要的图形特效，或使用轻量级桌面环境如 XFCE。
OSWorld 任务总是失败，如何调试？ ▼
先手动在虚拟机中执行任务，确认环境正常；再检查 Agent 的提示词是否清晰，或降低任务复杂度逐步测试。
能否在物理机上直接运行？ ▼
可以，但 OSWorld 设计为在虚拟机中运行以避免影响主机，物理机需注意隔离和备份。
