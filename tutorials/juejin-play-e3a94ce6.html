传统图片分析工具通常把用户照片上传到服务器再调用 AI 模型，流程重、成本高，还有隐私风险。但像人脸关键点检测、面部比例计算这类轻量任务，完全可以在浏览器端用 MediaPipe 的 WASM 推理完成。Nuxt 4 提供了优秀的 SSR 和客户端组件能力，配合 MediaPipe Face Mesh 可以做到零后端依赖。这个玩法适合做颜值打分、虚拟试妆、表情互动等前端工具，也适合作为学习浏览器端 AI 推理的入门项目。

📝 一步步教你做

1

第1步：初始化 Nuxt 4 项目并安装依赖

在终端执行 npx nuxi@latest init face-mesh-demo 创建项目，进入目录后 npm install。然后安装 MediaPipe 任务包：npm install @mediapipe/tasks-vision。启动开发服务器 npm run dev，确认默认页面能正常访问。
💡 小贴士：如果网络慢，可以配置 npm 镜像源；Nuxt 4 默认使用 app/ 目录结构，注意文件路径。
2

第2步：准备人脸关键点模型文件

从 MediaPipe 官方模型页下载 face_landmarker.task 模型文件，放到 Nuxt 项目的 public/models/ 目录下。这个模型文件约几 MB，浏览器首次加载后会缓存。在代码中通过 /models/face_landmarker.task 路径引用即可。
💡 小贴士：模型文件不要放在 assets 目录，public 下的静态资源才能被浏览器直接访问。
3

第3步：封装客户端人脸检测组件

在 components/ 下新建 FaceMeshAnalyzer.client.vue，使用 .client 后缀确保只在浏览器运行。在 onMounted 中通过 FilesetResolver.forVisionTasks 加载 WASM，再创建 FaceLandmarker 实例，配置 runningMode 为 IMAGE。暴露一个 analyze(imageElement) 方法，调用 detect 返回关键点数组。
💡 小贴士：MediaPipe 的 WASM 文件路径要用 CDN 或本地复制，推荐用官方 CDN 避免路径问题。
4

第4步：实现图片上传与关键点绘制

在页面中放一个 file input 和 canvas，用户选择图片后读取为 Image 对象，传给 analyze 方法。拿到 478 个关键点后，用 canvas 的 fillRect 或 arc 把每个点画出来，也可以只画轮廓线。同时计算面部比例，比如两眼距离与脸宽的比值，显示在页面上。
💡 小贴士：绘制前记得清空 canvas，图片按原始尺寸绘制避免坐标错位。
5

第5步：优化体验与错误处理

添加加载状态提示，模型加载完成前禁用上传按钮。处理非人脸图片的情况，检测结果为空时给出友好提示。用 URL.createObjectURL 预览图片，组件卸载时 revoke 释放内存。最后在 nuxt.config.ts 中确认没有 SSR 相关报错。
💡 小贴士：可以在页面加一个“示例图片”按钮，方便用户快速体验，不用自己找图。

✨ 完成后你会得到

打开页面后上传一张人脸照片，浏览器本地完成检测，canvas 上叠加显示人脸关键点，页面同时展示计算出的面部比例数值。整个过程没有网络请求上传照片，刷新后模型会从缓存快速加载。

❓ 常见问题

为什么必须用 .client.vue 后缀？ ▼
MediaPipe 依赖浏览器 API（如 WebAssembly、Canvas），在服务端渲染时会报错，.client 后缀让组件只在客户端挂载。
模型加载很慢怎么办？ ▼
首次加载需要下载 WASM 和模型文件，建议部署时把模型放到 CDN 或开启 gzip/brotli 压缩，后续会走浏览器缓存。
能检测视频流吗？ ▼
可以，把 FaceLandmarker 的 runningMode 改为 VIDEO，配合 requestAnimationFrame 循环调用 detectForVideo 即可。
关键点数量是多少？ ▼
MediaPipe Face Landmarker 默认输出 478 个 3D 关键点，包含面部轮廓、眼睛、嘴唇等区域。
需要后端吗？ ▼
完全不需要，所有推理在浏览器本地完成，适合静态部署到 Vercel、Netlify 等平台。
