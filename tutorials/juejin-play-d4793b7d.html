用Cloudflare一键为网站建智能体搜索接口

🎯 为什么值得玩

随着 AI 智能体（Agent）的普及，网站不仅要服务人类用户，还要方便机器读取和搜索。Cloudflare 推出的 Search for Agents 功能，能自动抓取并索引你的站点内容，生成标准化的搜索接口。这个玩法适合博客、文档站、电商产品页等任何希望被 AI 助手检索和引用的网站。无需编写爬虫或维护向量数据库，Cloudflare 帮你搞定全文转译和索引更新。

🧰 你需要准备

  • Cloudflare 账号 → 访问
    用于开启 Search for Agents 功能并管理站点
  • 已托管在 Cloudflare 的域名 → 访问
    网站 DNS 需通过 Cloudflare 解析，才能使用该功能
  • 网站内容（HTML 页面） → 访问
    需要被索引的页面，确保内容可公开访问

📝 一步步教你做

1

第1步：登录 Cloudflare 并选择站点

打开 Cloudflare Dashboard（https://dash.cloudflare.com），在首页的「网站」列表中选择你要启用 AI 搜索的域名。如果还没有站点，先按提示添加域名并完成 DNS 解析。
💡 小贴士：建议先在测试域名上操作，避免影响线上主站。
2

第2步：开启 Search for Agents 开关

进入站点管理页后，在左侧菜单找到「AI」或「Search for Agents」入口（不同版本位置略有差异，可在搜索框输入 Search for Agents 快速定位）。点击「Enable」或打开开关，Cloudflare 会自动开始抓取和索引你的站点内容。
💡 小贴士：首次索引可能需要几分钟到几小时，取决于站点页面数量。
3

第3步：验证 /.well-known/search 端点

开启后，Cloudflare 会自动在域名根路径下暴露 /.well-known/search 端点。在浏览器访问 https://你的域名/.well-known/search，应返回 JSON 格式的搜索接口描述（包含端点地址、参数说明等）。也可以用 curl 命令测试：curl https://你的域名/.well-known/search。
💡 小贴士：如果返回 404，检查是否已开启功能并等待索引完成；确保没有防火墙规则拦截该路径。
4

第4步：用智能体或脚本调用搜索接口

根据 /.well-known/search 返回的描述，构造搜索请求。通常向该端点发送 GET 请求并带上查询参数（如 ?q=关键词），即可获得站内相关内容的 JSON 结果。你可以用 Postman、curl 或任意支持 HTTP 的智能体框架（如 LangChain、Dify）来调用。
💡 小贴士：在智能体提示词中明确告知它先读取 /.well-known/search 了解接口规范，再发起搜索。
5

第5步：检查索引状态与内容覆盖

回到 Cloudflare 控制台的 Search for Agents 页面，查看已索引的页面数量和最近抓取时间。如果发现重要页面未被索引，检查该页面是否被 robots.txt 屏蔽或需要登录才能访问。
💡 小贴士：定期查看索引报告，确保新发布的内容能被及时收录。

✨ 完成后你会得到

访问 https://你的域名/.well-known/search 返回结构化的搜索接口描述；通过该端点发送查询能获得站内相关内容的 JSON 结果；Cloudflare 控制台显示索引页面数量持续增长。

❓ 常见问题

这个功能收费吗？ ▼
Search for Agents 目前包含在 Cloudflare 的免费计划中，但可能有索引页面数量或调用次数的限制，具体以官方定价页为准。
我的网站是动态渲染的（SPA），能被索引吗？ ▼
Cloudflare 会抓取渲染后的 HTML，但若内容完全依赖客户端 JavaScript 且加载较慢，可能影响索引效果。建议使用服务端渲染或静态生成。
如何控制哪些页面不被索引？ ▼
通过 robots.txt 的 Disallow 规则或页面 meta 标签（noindex）来排除不希望被索引的路径。
搜索接口支持中文吗？ ▼
支持。Cloudflare 的索引和搜索基于全文转译，对中英文内容都能处理，但分词效果可能因语言而异。
索引更新频率如何？ ▼
Cloudflare 会定期重新抓取站点，新内容通常在几小时到一天内被收录。也可以在控制台手动触发重新索引。

🚀 进阶玩法

  • 🔹 变体1：结合 Cloudflare Workers 自定义搜索接口的返回格式，增加过滤、排序或高亮字段，适配特定智能体框架。
  • 🔹 变体2：将 /.well-known/search 端点接入 Dify 或 LangChain 的工具链，让智能体自动发现并调用站内搜索，构建问答机器人。
  • 🔹 变体3：为多语言站点分别开启索引，并在智能体提示词中根据用户语言选择对应搜索端点，实现跨语言检索。

打开 Cloudflare 的一个开关，就能让整站内容变成智能体可调用的标准搜索接口，零代码实现 AI 友好型网站。
