📝 一步步教你做

1

第1步：明确 3D 场景需求并编写提示词

先想清楚你要的 3D 交互效果：比如一个旋转的立方体、可拖拽的太阳系模型、或者点击变色的小球。然后写一段结构化提示词，包含：使用 Three.js 库、场景描述、交互方式（鼠标拖拽旋转/滚轮缩放/点击事件）、颜色和光照要求、输出为单个 HTML 文件。提示词越具体，生成代码越可用。
💡 小贴士：提示词里明确写“使用 CDN 引入 Three.js，不要用 npm”，这样生成的 HTML 直接双击就能跑。
2

第2步：调用腾讯混元 Hy4 Flash 生成代码

打开腾讯云混元大模型控制台，选择 Hy4 Flash 模型，把上一步的提示词粘贴进去发送。等待几秒到十几秒，模型会返回完整的 HTML 代码。如果第一次生成不完整，可以追加“请输出完整代码，不要省略”再试一次。成本约两毛钱一次调用。
💡 小贴士：生成后先检查代码里是否包含 <script src="https://cdn.jsdelivr.net/npm/three@0.160.0/build/three.min.js"></script> 这类 CDN 引用，没有就手动补上。
3

第3步：保存为 HTML 文件并在浏览器中运行

把生成的代码复制到 VS Code 或记事本中，保存为 index.html（编码选 UTF-8）。然后双击文件用 Chrome 打开，或者拖进浏览器窗口。如果页面空白，按 F12 打开控制台看报错，常见问题是 Three.js 版本不对或缺少 OrbitControls 引用。
💡 小贴士：如果用到 OrbitControls，记得同时引入 https://cdn.jsdelivr.net/npm/three@0.160.0/examples/js/controls/OrbitControls.js，并确保版本号一致。
4

第4步：调试交互与视觉效果

在浏览器中测试鼠标拖拽、滚轮缩放、点击等交互是否正常。如果旋转太快或太慢，调整代码里的 rotationSpeed 变量；如果颜色不对，修改 material 的 color 值。把报错信息或不满意的效果反馈给混元模型，让它给出修正代码，迭代一到两轮即可。
💡 小贴士：每次只改一个参数，改完刷新浏览器看效果，避免一次改太多导致混乱。
5

第5步：部署分享（可选）

如果想把 3D 网页发给别人看，可以把 index.html 上传到 GitHub Pages、Vercel 或 Netlify 等免费静态托管平台。也可以直接发 HTML 文件给对方，对方用浏览器打开即可。注意如果用了 CDN 资源，对方需要联网。
💡 小贴士：用 GitHub Pages 部署时，把文件放在仓库根目录，在 Settings 里开启 Pages 即可获得公开链接。

✨ 完成后你会得到

浏览器中打开一个可交互的 3D 网页：场景中有你指定的 3D 物体（如立方体、球体或模型），支持鼠标拖拽旋转视角、滚轮缩放，点击物体有颜色变化或动画反馈。页面加载流畅，控制台无报错。总成本约两毛钱。

❓ 常见问题

为什么页面打开是黑屏或空白？ ▼
最常见原因是 Three.js CDN 链接失效或版本不匹配。检查控制台报错，把 CDN 换成 https://cdn.jsdelivr.net/npm/three@0.160.0/build/three.min.js 并确保 OrbitControls 版本一致。另外确认浏览器支持 WebGL。
混元 Hy4 Flash 一次生成代码不完整怎么办？ ▼
在对话中追加“请输出完整 HTML 代码，不要省略任何部分，包括 CSS 和 JS”，或者让模型分段输出再手动拼接。也可以换用 DeepSeek 辅助补全缺失部分。
两毛钱是怎么算的？ ▼
腾讯混元 Hy4 Flash 按 token 计费，生成一个中等长度的 3D 网页代码大约消耗几千 token，费用在 0.2 元左右。具体价格以腾讯云官网实时计费为准。
需要会写 JavaScript 吗？ ▼
不需要。整个流程靠提示词驱动模型生成代码，你只需要会复制粘贴和保存文件。但懂一点基础能帮你更快定位和修改问题。
生成的 3D 网页能商用吗？ ▼
代码本身由 AI 生成，建议检查所用 Three.js 库的许可证（MIT，可商用），并确认模型服务条款。商用前最好人工审查代码质量和安全性。
