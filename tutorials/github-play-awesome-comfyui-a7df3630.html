📝 一步步教你做

1

第1步：安装 ComfyUI 与 ComfyUI-Manager

先下载 ComfyUI 官方便携包或通过 git 克隆到本地，解压后运行 run_nvidia_gpu.bat（N卡）或 run_cpu.bat。接着进入 ComfyUI/custom_nodes 目录，执行 git clone https://github.com/ltdrdata/ComfyUI-Manager.git。重启 ComfyUI 后，界面右侧会出现 Manager 按钮，表示安装成功。
💡 小贴士：如果你是 Windows 用户，直接下载 ComfyUI 的 portable 版本最省事，避免 Python 环境冲突。
2

第2步：克隆工作流合集仓库

打开终端或 Git Bash，进入你存放 ComfyUI 工作流的目录（通常是 ComfyUI/user/default/workflows）。执行 git clone https://github.com/yolain/ComfyUI-Yolain-Workflows.git。克隆完成后，你会看到按类别分好的文件夹，比如 01-文生图、02-图生图、03-放大等。
💡 小贴士：如果不想用 git，也可以直接在 GitHub 页面点击 Code -> Download ZIP，解压后把 JSON 文件拖进 ComfyUI 界面。
3

第3步：安装缺失节点（comfyui-easy-use 等）

打开 ComfyUI，点击右侧 Manager 按钮，选择 Install Missing Custom Nodes。Manager 会自动扫描你加载的工作流中缺失的节点，并列出 comfyui-easy-use 等依赖。勾选全部后点击 Install，等待安装完成后重启 ComfyUI。
💡 小贴士：如果 Manager 没有自动识别，可以手动在 Manager 的 Install Custom Nodes 里搜索 comfyui-easy-use 并安装。
4

第4步：加载并运行第一个工作流

在 ComfyUI 界面点击 Load 按钮，从克隆的仓库文件夹中选择一个基础文生图工作流（例如 01-文生图/基础文生图.json）。加载后，检查 Load Checkpoint 节点是否指向了你本地已有的模型文件。如果没有，在下拉菜单中切换成你的模型。然后点击 Queue Prompt，等待出图。
💡 小贴士：第一次运行建议把采样步数调低（如 20 步），分辨率设为 512x512，快速验证流程是否通畅。
5

第5步：按需修改参数与节点

工作流跑通后，你可以自由修改提示词、采样器、CFG、种子等参数。comfyui-easy-use 提供了很多简化节点，比如 EasyLoader、EasyPositive 等，让连线更直观。如果想调整构图，可以替换 ControlNet 节点或添加 LoRA 加载器。
💡 小贴士：修改前先另存一份工作流副本，避免覆盖原始模板。
6

第6步：保存并复用你的工作流

调整满意后，点击 Save 按钮，将工作流保存为 JSON 文件到本地。下次可以直接拖入 ComfyUI 或通过 Load 加载。你还可以把常用参数固化，做成自己的模板库，方便批量出图。
💡 小贴士：给工作流起一个带日期和用途的名字，比如 2025-04-文生图-写实风.json，方便日后查找。

✨ 完成后你会得到

成功加载并运行至少一个工作流，看到 ComfyUI 输出一张符合提示词的图像。同时，你掌握了从克隆仓库、安装依赖到修改参数、保存复用的完整流程，能够独立探索合集中的其他工作流。

❓ 常见问题

加载工作流后提示缺少节点怎么办？ ▼
打开 ComfyUI-Manager，点击 Install Missing Custom Nodes，它会自动检测并安装缺失的节点包。如果仍然报错，手动搜索节点名并安装，然后重启 ComfyUI。
工作流里的模型我都没有，必须下载一模一样的吗？ ▼
不一定。你可以把 Load Checkpoint 节点换成自己已有的模型，但要注意模型类型（SD1.5/SDXL）与工作流其他节点兼容。如果效果差异大，再考虑下载推荐模型。
为什么出图速度很慢？ ▼
检查是否使用了 CPU 模式，建议开启 GPU 加速。另外降低分辨率、减少采样步数、使用更快的采样器（如 DPM++ 2M Karras）都能提速。
comfyui-easy-use 和 ComfyUI 自带节点有什么区别？ ▼
comfyui-easy-use 对常用功能做了封装，节点更少、连线更简单，适合新手快速搭建。但底层逻辑与原生节点一致，熟练后可以混用。
这个合集里的工作流可以商用吗？ ▼
工作流本身是开源免费的，但你要注意其中使用的模型、LoRA、ControlNet 等资源的授权协议。商用前请逐一确认版权。
