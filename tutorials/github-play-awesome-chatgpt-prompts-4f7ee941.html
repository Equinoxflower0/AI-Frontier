📝 一步步教你做

1

第1步：打开仓库，找到你需要的提示词分类

访问 https://github.com/f/prompts.chat ，在README中你会看到按角色和场景分类的提示词列表，比如“Act as a Linux Terminal”“Act as a JavaScript Console”“Act as a Financial Analyst”等。点击任意提示词标题，就能看到完整的提示词内容。建议先浏览目录，找到与你当前任务最匹配的3-5个提示词。
💡 小贴士：不要贪多，先选一个最贴近你需求的提示词，直接复制到ChatGPT里试效果。
2

第2步：复制提示词并粘贴到ChatGPT

在GitHub页面点击提示词旁边的复制按钮，或者手动选中提示词全文（通常以“I want you to act as...”开头）。打开ChatGPT新对话，把提示词粘贴进去，然后按回车发送。ChatGPT会回复“OK”或类似确认，表示它已经进入角色。
💡 小贴士：如果提示词里有占位符如[主题]、[语言]，先替换成你的具体内容再发送。
3

第3步：补充你的具体任务，获取专业输出

在ChatGPT确认角色后，直接输入你的具体问题或任务。例如你用了“Act as a Financial Analyst”，就可以输入“帮我分析一下特斯拉2024年Q1财报的关键风险点”。ChatGPT会按照提示词设定的专业身份和输出格式来回答。如果输出不够满意，可以追加“请更详细”“用表格呈现”等指令。
💡 小贴士：把ChatGPT的第一次回复当作草稿，用“继续”“优化”“换一种风格”来迭代，效果会更好。
4

第4步：收藏和整理你的常用提示词

在GitHub仓库里，你可以给喜欢的提示词点Star，或者把内容复制到自己的Notion、飞书、Obsidian等笔记工具中，按“写作”“编程”“营销”等标签分类。建议建立一个“提示词库”文档，每次用完后记录效果和修改版本，形成自己的提示词资产。
💡 小贴士：用浏览器书签直接收藏GitHub上具体提示词的锚点链接，下次一键直达。
5

第5步（可选）：自托管私有提示词库

如果你在团队内使用，或者想完全私有化，可以克隆仓库并自部署。仓库提供了Docker和Node.js两种方式。基本命令：git clone https://github.com/f/prompts.chat.git，然后进入目录，运行docker compose up 或 npm install && npm run dev。部署后你就能在内网访问自己的提示词库，数据完全私有。
💡 小贴士：自托管适合企业内部分享，但需要一定的运维基础；个人用户直接用GitHub在线版就够了。

这些提示词是免费的吗？ ▼
完全免费且开源，你可以随意使用、修改和分享，甚至商用。
我需要会写代码才能用吗？ ▼
不需要。99%的提示词都是纯文本，复制粘贴到ChatGPT即可，只有自托管才需要一点技术基础。

原版提示词大多是英文，但你可以直接翻译成中文使用，ChatGPT同样能理解。建议保留英文角色设定，任务描述用中文。

可能是任务描述不够具体，或者模型版本不同。尝试补充背景信息、指定输出格式，或换用GPT-4。
