第2步：选择一个预置场景并输入指令

第4步：用 API 方式复现（可选但推荐）

如果你有 Postman，找到试具页面的“API 文档”或“开发者”标签，复制请求示例。在 Postman 中填入 endpoint 和你的试具 token（如有），发送一个 POST 请求，body 里带上场景 ID 和指令文本。查看返回的 JSON 结构，理解模型输出的字段含义。

第5步：记录结果并形成小报告

把每次运行的指令、参数、输出截图和你的观察整理到一个表格里。重点记录：模型在什么指令下表现好、什么情况下失败、参数如何影响成功率。这份记录就是你后续进阶玩法的基线。

没有机器人硬件能玩吗？ ▼
可以。这个玩法就是纯在线试具，模型在云端推理，你只需要浏览器，不需要任何实体机器人。
为什么我的指令模型没反应？ ▼
先检查指令是否过于模糊，尝试加入物体、颜色、动作等具体词；再确认场景选择与指令匹配，比如避障场景不要输入抓取指令。
API 调用返回 401 或 429 怎么办？ ▼
401 表示缺少或错误 token，检查请求头 Authorization；429 表示触发限频，降低请求频率或等待一段时间。
试具的结果能直接用于真实机器人吗？ ▼
在线试具主要用于验证模型能力，输出是仿真层面的动作建议；迁移到真实机器人还需要做标定、安全约束和硬件适配。
