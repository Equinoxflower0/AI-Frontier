第1步：获取 LongCat 模型与代码

访问美团 LongCat 团队在 GitHub 或 Hugging Face 上的开源页面（可通过智东西报道中的链接找到入口），克隆代码仓库到本地。使用 git clone 命令下载项目，并按照 README 指引安装依赖（通常为 pip install -r requirements.txt）。如果模型权重需要单独下载，请使用 huggingface-cli 或 git lfs 拉取。
💡 小贴士：建议先阅读仓库的 README 和模型卡片，确认硬件要求和许可证，避免下载不兼容的版本。
2

第2步：配置本地推理环境

创建 Python 虚拟环境（如 conda create -n longcat python=3.10），激活后安装 PyTorch 和项目依赖。若使用 GPU，确保 CUDA 版本与 PyTorch 匹配。对于显存较小的设备，可以启用量化加载（如 4-bit 或 8-bit）以减少内存占用。检查 transformers、accelerate 等库是否安装正确。
💡 小贴士：运行 python -c "import torch; print(torch.cuda.is_available())" 验证 GPU 是否可用，若为 False 请检查驱动和 CUDA 安装。
3

第3步：启动模型服务

根据项目文档选择启动方式：若使用 Ollama，可编写 Modelfile 导入 LongCat 模型并运行 ollama serve；若使用 vLLM，则通过 python -m vllm.entrypoints.openai.api_server --model <模型路径> 启动兼容 OpenAI API 的服务。启动后，用 curl 或 Python requests 测试 /v1/completions 或 /v1/chat/completions 接口是否返回正常。
💡 小贴士：记录服务端口（默认 8000 或 11434），后续工作流中需要填写该地址。首次加载模型可能较慢，耐心等待日志显示“ready”。

第4步：编写提示词模板与调用脚本

创建一个 Python 脚本，使用 requests 或 openai 库向本地服务发送请求。设计一个简单的提示词模板，例如“请根据以下图片描述生成一段产品文案：{image_description}”。将文本输入和图像路径（若模型支持多模态）组织成 JSON 载荷，调用 API 并解析返回结果。可以封装成函数，方便批量处理。
💡 小贴士：在脚本中加入异常处理和重试机制，避免因服务暂时无响应导致任务中断。
5

第5步：串联工作流并测试

将多个任务串联起来：例如先用模型对本地图片进行描述生成，再将描述文本送入另一个提示词生成营销文案，最后保存到 Markdown 文件。可以使用简单的 for 循环遍历文件夹中的图片，依次调用本地 API。运行脚本，观察输出是否连贯、格式是否正确。根据结果调整提示词或参数（如 temperature、max_tokens）。
💡 小贴士：先用 2-3 张图片做小规模测试，确认流程通畅后再批量处理，节省调试时间。

❓ 常见问题

没有 GPU 可以运行吗？ ▼
可以，但速度较慢。建议使用量化版本（如 GGUF 格式）并通过 Ollama 在 CPU 上运行，或使用云 GPU 临时测试。
模型下载太慢怎么办？ ▼
可以使用 Hugging Face 镜像站（如 hf-mirror.com）或提前用 git lfs 拉取。国内用户也可关注 ModelScope 上是否有对应模型。
启动服务时报错“CUDA out of memory”如何解决？ ▼
降低 batch size、启用量化加载（load_in_8bit=True），或换用更小的模型变体。也可限制 max_model_len 减少显存占用。
如何让工作流支持多轮对话？ ▼
在调用 API 时维护一个 messages 列表，每次将历史对话和最新用户输入一起发送，并保留模型返回的回复追加到列表中。
