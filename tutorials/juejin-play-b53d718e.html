很多人用 DeepSeek 只是聊天问答，其实它还能通过官方开源工具 DeepSeek Harness（DSH）接入本地文件、自定义界面和插件，变成生产力工作台。这个玩法适合内容创作者、设计师、独立开发者，以及需要管理本地文献的研究者。你不需要写复杂代码，跟着步骤配置就能让 AI 直接操作你的素材和工具。相比通用聊天，专属工作台能大幅减少重复复制粘贴，让 AI 真正融入你的工作流。

📝 一步步教你做

1

第1步：安装并启动 DeepSeek Harness

打开终端，执行 git clone https://github.com/deepseek-ai/harness.git 克隆仓库，进入目录后运行 npm install 安装依赖。接着复制 .env.example 为 .env，填入你的 DeepSeek API Key。最后运行 npm run dev 启动本地服务，浏览器访问 http://localhost:3000 就能看到 DSH 的初始界面。
💡 小贴士：如果 npm install 报错，先检查 Node.js 版本是否 ≥18，并尝试切换 npm 镜像源。
2

第2步：配置工作台基础参数

在 DSH 根目录找到 config/default.json，修改 model 为 deepseek-chat，并设置 temperature 为 0.7。在 plugins 数组中启用你需要的插件，例如 file-reader、markdown-render、ui-canvas。保存后重启服务，界面左侧会出现插件面板。
💡 小贴士：初次使用建议只启用 1-2 个插件，避免界面过于复杂，后续再逐步添加。
3

第3步：接入本地素材库（以文献库为例）

在 DSH 界面点击「添加数据源」，选择本地文件夹路径，DSH 会自动索引其中的 PDF、Markdown 和 TXT 文件。然后在对话输入框用 @ 引用具体文件，AI 就能基于文件内容回答。你也可以在 config 中设置自动索引的文件夹，实现打开即用。
💡 小贴士：文件较多时首次索引会慢一些，建议按主题分文件夹存放，方便 AI 精准检索。
4

第4步：定制你的专属界面（自媒体排版台/UI 画布）

在 plugins 目录下新建一个文件夹，复制示例插件模板，修改 manifest.json 中的名称和图标。然后在 index.js 中定义输入框的快捷指令，比如输入 /排版 就调用 Markdown 渲染插件输出公众号格式。保存后刷新页面，输入框旁会出现你的自定义按钮。
💡 小贴士：可以先从修改现有插件的文案和图标开始，熟悉结构后再写逻辑，降低上手难度。
5

第5步：测试完整工作流并保存为模板

在输入框输入一段测试内容，选择你配置的插件（如「自媒体排版」），观察输出是否符合预期。调整 prompt 模板和插件参数直到满意，然后点击界面右上角的「保存为工作台模板」，下次打开 DSH 可直接加载。
💡 小贴士：把常用指令写成 prompt 模板文件放在 templates 目录，团队协作时可以直接共享。

✨ 完成后你会得到

完成以上步骤后，你的 DeepSeek 界面将变成一个带插件面板的专属工作台：左侧可管理本地文献库，输入框支持快捷指令，能一键完成自媒体排版、UI 原型草图或游戏素材生成。每次打开 DSH 都会加载你保存的模板，无需重复配置。

❓ 常见问题

DSH 和直接使用 DeepSeek 网页版有什么区别？ ▼
DSH 是本地开源底座，能接入本地文件、自定义界面和插件，把 AI 嵌入你的工作流；网页版是通用聊天，无法直接操作本地素材。
没有编程基础能玩吗？ ▼
可以。基础配置只需改 JSON 文件和复制模板，按教程操作即可；进阶插件开发才需要少量 JavaScript 知识。
API Key 会不会泄露？ ▼
Key 保存在本地 .env 文件，不会上传到第三方。注意不要将 .env 提交到 Git 仓库，建议加入 .gitignore。
支持哪些文件格式？ ▼
默认支持 PDF、Markdown、TXT、JSON 和图片，可通过插件扩展支持 Word、Excel 等格式。
DSH 是否免费？ ▼
DSH 本身开源免费，但调用 DeepSeek 模型需要按 API 用量付费，具体价格见 DeepSeek 官网。
