📝 一步步教你做

1

第1步：初始化 Tauri 2 项目

打开终端，运行 `npm create tauri-app@latest`，按提示输入项目名（如 reminder-launcher），选择前端框架（推荐 Vanilla 或 React），包管理器选 npm。进入项目目录后执行 `npm install` 安装依赖。最后运行 `npm run tauri dev` 确认默认窗口能正常启动。
💡 小贴士：如果遇到 Rust 编译错误，检查是否安装了 MSVC 构建工具，并确保 rustup 默认工具链为 stable-x86_64-pc-windows-msvc。
2

第2步：设计主界面与交互逻辑

在 src 目录下编辑前端页面，添加一个输入框用于输入指令，一个按钮用于提交。指令格式约定为：`提醒 10:30 开会`、`笔记 买牛奶`、`启动 notepad`。用 JavaScript 监听按钮点击，将输入内容通过 Tauri 的 invoke 函数发送到 Rust 后端。同时可以加一个简单的历史记录列表，展示最近的操作。
💡 小贴士：输入框支持回车提交，体验更顺手；用 localStorage 暂存历史记录，刷新不丢失。
3

第3步：Rust 后端实现三大功能

在 src-tauri/src/main.rs 中定义三个 Tauri command：`set_reminder` 解析时间并启动一个异步任务，到点后调用系统通知；`save_note` 将笔记内容追加写入本地文件（如 notes.txt）；`launch_app` 使用 std::process::Command 启动指定程序（如 notepad.exe）。每个 command 返回 Result 给前端反馈。
💡 小贴士：提醒功能可以用 tokio 的 sleep 实现，注意在 Tauri 的异步运行时中 spawn 任务；启动程序时对参数做简单校验，避免命令注入。
4

第4步：配置系统托盘与全局快捷键

在 tauri.conf.json 中启用托盘图标，并在 Rust 端使用 Tauri 的 TrayIconBuilder 创建托盘菜单，包含“显示主窗口”和“退出”。同时注册全局快捷键（如 Ctrl+Shift+Space）唤起窗口，方便随时输入指令。需要引入 tauri-plugin-global-shortcut 插件并在配置中启用。
💡 小贴士：托盘图标建议用 .ico 格式，尺寸 32x32；全局快捷键不要与系统常用快捷键冲突。
5

第5步：打包为 Windows 安装包

运行 `npm run tauri build`，Tauri 会自动编译 Rust 并打包前端资源，生成 .msi 和 .exe 安装包，位于 src-tauri/target/release/bundle/ 目录下。安装后即可在开始菜单找到应用，双击运行。如需开机自启，可在安装包配置中勾选或手动将快捷方式放入启动文件夹。
💡 小贴士：首次构建时间较长，耐心等待；若想减小体积，可在 tauri.conf.json 中开启压缩和移除未使用功能。

✨ 完成后你会得到

运行应用后，系统托盘出现图标，按下 Ctrl+Shift+Space 弹出输入框。输入“提醒 14:00 喝水”后，到点会收到 Windows 通知；输入“笔记 明天交报告”后，笔记被保存到本地文件；输入“启动 calc”后，计算器程序被打开。所有操作都有即时反馈，历史记录清晰可见。

❓ 常见问题

没有 Rust 基础能跟着做吗？ ▼
可以。教程提供的代码片段直接复制即可运行，重点理解 Tauri 的 command 机制和前端调用方式，Rust 语法只需看懂大致逻辑。
提醒功能在应用关闭后还能生效吗？ ▼
默认不能，因为提醒任务运行在应用进程内。如需离线提醒，可将提醒时间写入系统计划任务，或让应用常驻托盘不退出。
启动程序时如何传递参数？ ▼
在 launch_app 命令中接收一个参数列表，用 Command::new(program).args(args) 传入即可，注意对参数做转义处理。
打包后的应用体积多大？ ▼
Tauri 应用通常只有几 MB 到十几 MB，远小于 Electron。具体取决于前端资源和 Rust 编译优化选项。
能否在 macOS 或 Linux 上使用？ ▼
Tauri 本身跨平台，但本教程的托盘和快捷键实现针对 Windows 优化，其他平台需调整部分 API 和打包配置。
