📝 一步步教你做

1

第1步：克隆仓库并浏览目录结构

打开终端执行 git clone https://github.com/Shubhamsaboo/awesome-llm-apps.git，然后 cd 进去用 ls 查看分类目录。仓库通常按 starter_ai_agents、rag_tutorials、advanced_ai_agents 等文件夹组织，每个子目录里都有独立的 README.md 说明该应用的功能和运行方式。先花 5 分钟扫一遍目录名，挑一个你最感兴趣的场景。
💡 小贴士：如果 GitHub 克隆慢，可以用 ghproxy 或 Gitee 镜像加速；也可以直接点仓库页面右上角 Code → Download ZIP。
2

第2步：选定一个示例并创建虚拟环境

假设你选了 starter_ai_agents 里的某个 RAG 应用，先 cd 进该子目录。用 python -m venv venv 创建虚拟环境，然后 source venv/bin/activate（Windows 用 venv\Scripts\activate）激活。接着执行 pip install -r requirements.txt 安装依赖，如果目录里没有 requirements.txt，就按 README 里列出的包手动 pip install。
💡 小贴士：强烈建议每个示例单独建虚拟环境，避免不同项目依赖冲突；用 conda 也可以，命令换成 conda create -n agent python=3.10。
3

第3步：配置 API Key 和环境变量

在示例目录下创建 .env 文件，写入 OPENAI_API_KEY=sk-你的真实Key。如果示例用的是 LlamaIndex，通常还会读取 OPENAI_API_KEY 或 OPENAI_API_BASE。若你用的是国内兼容接口（如 DeepSeek），把 OPENAI_API_BASE 设为对应地址即可。保存后确认 .env 和代码在同一目录，或者代码里用 load_dotenv() 能定位到。
💡 小贴士：不要把 .env 提交到 Git；仓库一般有 .gitignore 帮你忽略，但自己再检查一遍更稳。
4

第4步：运行应用并观察输出

根据 README 的启动命令执行，常见有两种：python app.py 直接跑脚本，或 streamlit run app.py 启动 Web 界面。如果是 Streamlit，浏览器会自动打开 localhost:8501，你在输入框里提问就能看到 Agent 的回复和中间步骤。如果是纯脚本，终端会打印检索到的文档片段和最终答案。第一次跑建议用示例里自带的测试问题，确认链路通了再换自己的数据。
💡 小贴士：如果报 ModuleNotFoundError，多半是虚拟环境没激活或漏装包；如果报 401，检查 API Key 是否复制完整、余额是否充足。
5

第5步：替换成你自己的数据或提示词

RAG 类示例通常有一个 data 文件夹或代码里写死的文档路径，把你的 PDF、TXT、Markdown 丢进去，改一下路径就能用。Agent 类示例则在代码顶部有 system_prompt 或 agent 定义，改掉角色描述和工具列表，就能变成你的专属助手。改完重新运行，对比输出变化，体会不同提示词对 Agent 行为的影响。
💡 小贴士：改提示词时一次只改一个变量，方便定位效果差异；可以先把 temperature 调低到 0.2 让输出更稳定。

❓ 常见问题

我没有 OpenAI API Key，能用别的模型吗？ ▼
可以。仓库里很多示例支持通过 OPENAI_API_BASE 指向兼容 OpenAI 协议的接口，比如 DeepSeek、通义千问、Moonshot 等，把 Key 和 Base URL 换成对应值即可。
跑示例时提示缺少某个包怎么办？ ▼
先确认虚拟环境已激活，然后 pip install 缺失的包名。如果 requirements.txt 里版本冲突，可以尝试 pip install --upgrade 或按 README 建议的 Python 版本重建环境。
Streamlit 启动后浏览器打不开 localhost:8501？ ▼
检查终端是否真的输出 URL，有时端口被占用会换成 8502。也可以手动访问 http://localhost:8501，或加 --server.port 指定其他端口。
这些示例能直接商用吗？ ▼
仓库本身是开源合集，但每个子项目可能各有 License，商用前请查看对应目录的 LICENSE 文件，并注意模型 API 的使用条款。
哪个示例最适合新手入门？ ▼
建议从 starter_ai_agents 里的单 Agent + 工具调用示例开始，代码量少、依赖简单，跑通后再挑战多智能体和 RAG 进阶项目。

🚀 进阶玩法

  • 🔹 变体1：把 RAG 示例的数据源从本地文件换成网页爬取，用 LlamaIndex 的 SimpleWebPageReader 实时抓取新闻做问答。
  • 🔹 变体2：把单 Agent 示例改造成多智能体协作，用 CrewAI 或 AutoGen 让一个 Agent 负责检索、一个负责总结、一个负责审核。
  • 🔹 变体3：给 Agent 加上长期记忆，接入向量数据库（如 Chroma、Qdrant），让它在多轮对话中记住用户偏好和历史结论。
