第2步：按需求筛选插件或代理

在 README 中使用 Ctrl+F 搜索关键词，比如 “agent”、“theme”、“plugin”。每个条目通常包含名称、一句话描述和 GitHub 链接。优先选择 stars 数高、最近有更新的项目。把感兴趣的链接复制到记事本或浏览器书签。

第3步：安装并配置选中的插件/代理

以插件为例，进入对应 GitHub 仓库，通常 README 会给出安装命令，如 `npm install opencode-plugin-xxx` 或 `opencode plugin add xxx`。按照说明修改 OpenCode 配置文件（如 `~/.opencode/config.json`），添加插件名称和参数。代理类资源可能需要克隆仓库并运行 `npm run start`。
💡 小贴士：安装前先备份原配置文件，避免插件冲突导致 OpenCode 无法启动。
4

第4步：在 OpenCode 中启用并测试

重启 OpenCode 服务或重新加载配置。在对话界面输入一个测试 prompt，观察插件是否生效（例如自动格式化代码、调用外部 API）。如果代理需要单独启动，确保其端口与 OpenCode 配置一致。查看 OpenCode 日志确认无报错。
💡 小贴士：如果插件无响应，先检查 OpenCode 版本是否兼容，多数插件要求 >=0.5.0。

❓ 常见问题

这个列表和 OpenCode 官方插件市场有什么区别？ ▼
官方市场可能只收录审核过的插件，而 Awesome 列表是社区驱动，收录范围更广，包括实验性项目和主题，更新更快。
我安装插件后 OpenCode 启动报错怎么办？ ▼
先禁用最近安装的插件，检查版本兼容性。多数插件要求 OpenCode >=0.5.0，可运行 `opencode --version` 确认。查看插件 README 的“Troubleshooting”部分。
列表里的代理（Agent）和插件（Plugin）有什么区别？ ▼
插件通常直接嵌入 OpenCode 进程，扩展其功能；代理是独立运行的服务，通过 API 与 OpenCode 通信，适合复杂任务如多步推理、外部工具调用。
如何判断一个资源是否值得使用？ ▼
看 stars 数、最近 commit 时间、Issue 活跃度、是否有详细文档。优先选择 100+ stars 且半年内有更新的项目。
我可以同时安装多个插件吗？ ▼
可以，但注意插件之间可能冲突（如两个都修改同一快捷键）。建议逐个安装并测试，确认稳定后再加下一个。
