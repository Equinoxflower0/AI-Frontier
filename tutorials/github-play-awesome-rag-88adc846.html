📝 一步步教你做

1

第1步：安装依赖并配置 API Key

在终端执行 pip install llama-index openai。然后设置环境变量 OPENAI_API_KEY=你的密钥（Windows 用 set，Mac/Linux 用 export）。如果使用本地模型，可安装 llama-index-llms-ollama 并配置 base_url。
💡 小贴士：建议把 API Key 写入 .env 文件并用 python-dotenv 加载，避免泄露。
2

第2步：准备你的私有知识库

新建 data 文件夹，放入 2-3 个 txt 或 pdf 文件（例如公司产品文档、个人笔记）。LlamaIndex 支持多种格式，本教程用 SimpleDirectoryReader 自动读取。
💡 小贴士：文件内容尽量结构化，避免扫描版 PDF，否则需要额外 OCR。
3

第3步：构建索引并持久化

用 SimpleDirectoryReader 加载文档，调用 VectorStoreIndex.from_documents(documents) 生成向量索引。然后执行 index.storage_context.persist('./storage') 保存到本地，下次直接加载，省去重复 embedding 费用。
💡 小贴士：如果文档很大，先用 SentenceSplitter 分块，chunk_size 设为 512-1024 效果较好。
4

第4步：创建查询引擎并提问

通过 index.as_query_engine(similarity_top_k=3) 得到查询引擎。然后输入问题，例如「我们产品的退货政策是什么？」，引擎会先检索相关片段再交给 LLM 生成答案。打印 response 即可看到结果。
💡 小贴士：开启 response_mode='compact' 可减少 token 消耗，适合长文档。
5

第5步：对照 Awesome RAG 分类体系做扩展

打开 https://github.com/hymie122/RAG-Survey，阅读其提出的「基础-增强-应用」分类。尝试在你的代码中加入一个增强模块，比如查询改写（Query Rewrite）或重排序（Rerank），观察效果变化。
💡 小贴士：LlamaIndex 内置 HyDE、SentenceWindowNodeParser 等增强组件，直接替换即可。

你将在本地拥有一个可运行的 RAG 问答系统，能针对自己的文档回答具体问题，并输出引用来源。同时你已理解 RAG 论文分类框架，知道下一步该优化哪个环节。

❓ 常见问题

没有 OpenAI API Key 怎么办？ ▼
可以用 Ollama 本地运行 Llama 3 或 Qwen，配合 llama-index-llms-ollama 和 llama-index-embeddings-huggingface，完全免费。
检索结果不准确怎么调？ ▼
先检查分块大小，再尝试增加 similarity_top_k，或加入 Rerank 模型（如 BAAI/bge-reranker-base）。
索引持久化后如何重新加载？ ▼
用 StorageContext.from_defaults(persist_dir='./storage') 和 load_index_from_storage(storage_context) 即可。
Awesome RAG 论文太多，从哪看起？ ▼
先看 Survey 原文的 taxonomy 图，再按「基础→增强→应用」顺序挑 3-5 篇高引论文精读。
LlamaIndex 和 LangChain 选哪个？ ▼
LlamaIndex 更专注 RAG 索引和检索，上手快；LangChain 生态更广。初学者建议先用 LlamaIndex 跑通流程。
