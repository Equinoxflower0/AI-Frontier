📝 一步步教你做

1

第1步：打开合集仓库，按分类浏览

访问 https://github.com/jamez-bondos/awesome-gpt4o-images ，在 README 中可以看到按风格、主题或模型分类的图片和提示词。建议先看“目录”或“Table of Contents”，找到你感兴趣的方向，比如“写实人像”“3D 卡通”“电影海报”“表情包”。点击图片或标题会展开对应的 prompt 文本。
💡 小贴士：如果仓库内容很多，直接用浏览器搜索（Ctrl+F）关键词，比如“cyberpunk”“watercolor”“logo”，能快速定位。
2

第2步：复制提示词，在 ChatGPT 中试跑

选中你喜欢的图片下方的 prompt 文本，完整复制。打开 ChatGPT，新建对话，选择 GPT-4o 模型，直接粘贴提示词并发送。等待几秒到几十秒，ChatGPT 会生成对应图片。如果第一次效果不理想，不要改提示词，先点“重新生成”看随机性。
💡 小贴士：GPT-4o 对英文提示词理解更准，如果原 prompt 是英文，建议保持英文；如果是中文，也可以直接跑，但可尝试翻译成英文对比效果。
3

第3步：微调提示词，替换主体和风格

找到原提示词中的主体词、风格词、颜色词、构图词，逐个替换成你想要的。例如把“a cat”换成“a corgi”，把“cyberpunk”换成“steampunk”，把“neon lights”换成“soft pastel colors”。每次只改 1-2 个变量，方便对比效果。改完后重新发送，观察变化。
💡 小贴士：保留原提示词的结构和修饰词顺序，只替换关键词，成功率最高。不要一次性大改，否则容易崩图。
4

第4步：保存你的最佳提示词和出图

把效果好的 prompt 和对应图片保存到本地或笔记软件（如 Notion、Obsidian）。建议按“风格_主体_日期”命名，例如“cyberpunk_city_2025-01”。如果愿意，可以 fork 仓库，把你的提示词和图片提交 Pull Request，贡献给社区。
💡 小贴士：在 ChatGPT 中可以直接右键保存图片，提示词建议同时存一份纯文本，方便以后复制。
5

第5步：用 Sora 生成动态版本（可选）

如果你有 Sora 权限，可以把 GPT-4o 生成的图片作为参考图上传到 Sora，再输入类似“animate this image with slow camera pan”的提示词，生成短视频。也可以直接把原提示词改写成视频描述，让 Sora 从零生成动态画面。
💡 小贴士：Sora 对运动描述更敏感，建议在提示词中加入“camera movement”“lighting change”“loop”等词，效果更可控。

✨ 完成后你会得到

你会在 ChatGPT 中看到与合集示例风格接近的图片，并且能通过替换关键词生成自己的版本。最终你手里会有一组可复用的提示词模板，以及若干张由 GPT-4o 或 Sora 生成的原创图片/视频。

❓ 常见问题

没有 ChatGPT Plus 能用吗？ ▼
免费版 ChatGPT 每天有少量 GPT-4o 图像生成额度，但次数有限。如果频繁使用，建议升级 Plus 或使用 API（gpt-image-1）。
为什么我复制的提示词出图效果和示例不一样？ ▼
图像生成有随机性，且模型版本、系统提示、对话历史都会影响结果。建议多试几次，并保持提示词完整复制。
提示词是中文的，需要翻译成英文吗？ ▼
GPT-4o 支持中文提示词，但英文提示词通常更稳定、细节更准。可以中英各跑一次对比。
可以商用吗？ ▼
需遵守 OpenAI 的使用条款和版权政策。建议不要直接生成受版权保护的角色或品牌，商用前确认授权。
如何找到更多类似提示词？ ▼
除了这个仓库，还可以搜索“awesome ChatGPT prompts”“GPT-4o image prompts”等关键词，或关注相关 GitHub 话题。

🚀 进阶玩法

  • 🔹 变体1：把合集当作“风格迁移器”——选一张示例图，用 GPT-4o 的“以图生图”功能上传你的照片，再粘贴原提示词，让 AI 把你的照片转成该风格。
  • 🔹 变体2：批量生成同一主题的系列图——固定提示词中的风格词，只替换主体词（如不同动物、不同城市），快速做一套统一风格的头像或海报。
  • 🔹 变体3：结合 Sora 做“图生视频”故事板——先用 GPT-4o 生成 3-5 张连贯场景图，再逐张丢给 Sora 生成短片段，最后剪辑成小故事。

💡 一句话总结

这个玩法的精髓是：把高质量提示词合集当成“配方书”，先复制跑通，再替换变量微调，最后结合 Sora 做动态扩展，快速从 0 到 1 出神图。
